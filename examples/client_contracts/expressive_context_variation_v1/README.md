# Expressive context variation — immutable consumer examples

Assignment `DJC-CORE-EXPRESSIVE-CONTEXT-VARIATION-V1-20261010`.
`pin.json` identifies the admission base, producer content pin, complete
before/after Runtime evidence and unchanged shared renderer 1.1 build pin.
`snapshots.json` contains the actual published snapshots from the 100 candidate
Runtime sequences: five existing families, five languages and four personas.
Inputs are synthetic, source-shaped fixtures; production eligibility,
deduplication, Planner placement and Broadcast projection execute normally.

Consumers render server-owned text and original attribution verbatim. There are
no new wire fields, Moment types, native delivery channels or auth scopes.
Artist birth/formation/descriptor and album edition facts keep their existing
visual-only boundary; selected Genre context keeps its existing channels.
Private Q/A, Profile, archives and conversation/history/search are outside the
shared projection and are never inputs to expressive realization.

The 400-case browser acceptance covers local integration/static Cast builds in
portrait/landscape, 800 actual cards, source links, transitions, reconnect,
empty browser storage and session end. A separate four-case probe covers
expiry and reconnect without resurrecting expired cards. Real HA HTTP and
WebSocket execute; CAF delivery is modeled. These are software examples, not
installed HA, native Apple or physical Cast/LG qualification. No receiver push,
Pages deployment or new renderer build is implied.
