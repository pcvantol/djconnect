# Configured voice preview v1 — local owner fixtures

Generated by `tests.test_voice_preview` through actual Core paired authority,
confirmed Settings3, operation journal, configured-processor admission, private
audio owner and shared speaker-delivery owner. External TTS/speaker I/O is
synthetic. The fixture contains no real user/profile, credentials or real audio.

`operation-fixtures.json` records the actual requests and owner results, including
the original operation receipt. Transport identity comes from the ordinary paired
request; callers supply only `contract_version:1` and a five-family `language`
inside the existing `speech/preview` operation. An existing authorized HTTP/paired
WS transport remains required. Language must match the qualified HA pipeline;
Core does not silently change its locale or choose another provider.

These are integration-preparation examples on base `1c3703c9`, not a protected
producerpin, installed capability or permission to start consumer work. Existing
Apple owns Preview/Stop/native playback. Fixed neutral comparison text is distinct
from narrative Persona/Mood contributions. No model call or fake Moment.

Confirmed duplicate requests return original receipt metadata without another
rich result, synthesis or dispatch. Socket cancellation does not automatically
undo an already admitted operation; read its outcome and never retry as a new
intent. A subsequent deliberate press may reuse the existing authorized sample
without extending its expiry. `text_only` blocks new and previously prepared
audio. `queued`/synthetic bytes do not prove audible playback.

The seventeen fixture tests are a source/owner contract proof. Configured real HA
synthesis, installed/native presentation and physical listening remain OPEN.
