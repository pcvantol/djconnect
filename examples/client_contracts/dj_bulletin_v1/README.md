# DJ Bulletin v1 consumer fixture

Core1291 / Apple182. This additive ordinary Moment has `type: dj_bulletin`,
`generation_metadata.bulletin_schema: "1"`, owner-only delivery, an empty summary,
no artwork/actions, and two attributed source metadata records. It is not an
Ask DJ response, Forecast, push payload or VibeCast family.

`actual-ha-wire.json` is derived from the retained original isolated HA receipt,
not a hand-authored successful runtime example. RSS and model response transports
and initial external music acquisition are declared synthetic. The fixture pins
its actual producer and harness and claims no installation or native execution.

Use `sample.owner_snapshot` and its ordinary Moment/Flow/native/speech fields.
Only the named current admission can render or speak. `speech_off` remains
manual-only; `speech_on` uses the existing client autoplay option. Both carry the
same original publication+30-minute source expiry and attributed sources. Reads,
reconnect, scrolling, speech and 304 responses must never renew that expiry.
`revoked_native_delivery` denies current/Flow access after original authority is
withdrawn. Expiry, service unload, owner/source/agent or settings changes revoke
admission; clients drop an unavailable contribution instead of retaining its text.

Apple must render a single normal owner Flow bubble, reuse its existing speech
settings, and preserve existing voice/target/permission gates. Unknown Moment
families on older consumers fail closed: skip the unsupported bubble and speech,
keep surrounding Flow items, and never infer actions or route through Ask DJ or
VibeCast. Native view/autoplay/reconnect/localization/accessibility qualification
belongs to Apple and is still open. No new screen, toggles or audio player.

Historical storage retains only unavailable publication metadata; there is no
permission to promote feed excerpts or generated news into a retained archive.
