Synthetic inputs, actual isolated HA 2026.10 and ordinary device pairing.
`paired-status-before-after.json` records the old baseline and retired-producer
candidate, real playback responses, history sizes and separately invoked
generative Track Insight. No credentials or raw provider prompts are exported.

consumer contract; no new capability, Moment type, Ask DJ filter or Forecast
composition is required.

Existing historical `ambient_music_fact` / `spotify_playback_context` cards
remain readable. New proactive content belongs in the active Session, with
public attributed facts only on authorized shared hosts. Explicit Ask DJ,
voice, history/search and operational system cards retain their contracts.

Code pin is a local unpublished early candidate; source/publication and native
Apple consumer adoption remain separate gates. No Swift/receiver writes,
installed or hardware acceptance is implied.
