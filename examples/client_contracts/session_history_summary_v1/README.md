# Private Session history summary v1 — early producer fixtures

Generated from ordinary device pairing and real isolated HA Session routes,
SQLite acceptance, observer, Planner, immutable Moment publication and reopened
storage. Only external Spotify and existing HA conversation provider responses
are fixtures. No broad HA credentials are used or retained.

The predefined sequence accepts two canonical observed entries, one opening
Session Moment and one rights-qualified Spotify Album Moment. Thus publication
count is two while only one Moment body is permitted in history. Two seconds
of confirmed chill followed by more than fifty seconds energy yields energy.

List summaries are directly renderable; detail summaries use the existing
opaque header revision. Every metric revision/as_of equals its own header
snapshot. Values are provisional/final independently of coverage. Absence or
null is unknown, never zero. Stage1 counts accepted media-change observations,
not exact playback instances or full listens. Source withdrawal yields null /
withdrawn; incomplete observation capture is partial. No summary belongs to
shared Broadcast, VibeCast, notifications or widgets.

These are locally qualified producer fixtures, not a merged producer pin or
native Apple acceptance. Exact candidate review and protected delivery are open.

Revision tokens only compare exactly against their own containing header; never
parse detail tokens as integers or order/merge them across routes. Partial totals
are registered subsets, unknown/withdrawn are unavailable, and known0 is zero.

summary-states.json contains actual paired owner responses for zero, partial,
withdrawn and legacy-final-unknown. Its real observer sequence reaches the
8192-key bound; legacy compact rows absent are an explicit Store-data fixture.
