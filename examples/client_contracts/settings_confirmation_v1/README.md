# Settings confirmation Moment v1

`actual-ha-wire.json` is a synthetic, ordinary paired HTTP/SQLite qualification
against actual HA 2026.10.0. It binds the current Core source and the exact
retained original raw receipt hash. The fixture covers the accepted Mood,
Persona and Presence operations, original-ID replay/readback, owner-only native
admission, history-off, historical v2 entries and postcommit recovery.

Validate receipt shapes with `receipt.schema.json`; runtime authorization,
original clocks, closed typed provenance and semantic ordering are separately
covered by `tests/test_settings_confirmation.py`. The schema is a decoder
contract, never permission to synthesize a confirmation or change settings.

See `docs/product/SETTINGS_CONFIRMATION_MOMENT_V1.md`. Client presentation,
actual speech and installed acceptance remain open. Same draft PR1290;
no merge/install until Peter explicitly asks to merge.
