# Epic Completion Template

Use this to close an implementation epic.

## Epic summary

Summarize what the Epic changed and why it mattered.

Include:

- product outcome;
- architecture outcome;
- repositories affected;
- user-visible impact.

## Architecture changes

List architecture changes made by the Epic.

Include:

- domain ownership changes;
- resolver/use-case changes;
- API or contract changes;
- client capability changes;
- storage/migration changes;
- new or updated ADRs.

## Documents changed

List documents changed.

Include:

- foundation docs;
- operational docs;
- implementation docs;
- repository-specific docs;
- release notes;
- client contract fixtures.

## Repositories changed

List repositories changed and their role in the Epic.

| Repository | Role | PRs |
| --- | --- | --- |
| | | |

## Runtime impact

Describe runtime behavior changes.

Include:

- new flows;
- changed flows;
- removed flows;
- fallback behavior;
- capability changes.

## Breaking changes

List breaking changes.

For each:

- what broke;
- why it was accepted;
- migration or recovery path;
- affected clients/repositories.

## Migration

Describe migrations or cleanup paths.

Include:

- stored data;
- config entries;
- client caches;
- tokens/pairing state;
- release compatibility.

## Tests

List tests run and coverage added.

Include:

- local commands;
- CI status;
- contract tests;
- manual validation;
- known test gaps.

## Known follow-up work

List follow-up work that remains after the Epic.

Classify:

- P0;
- P1;
- P2;
- research.

## Backlog updates

List backlog changes made.

Include:

- completed items;
- new epics;
- deferred work;
- removed work.

## Innovation updates

List Innovation Lab updates.

Include:

- ideas promoted;
- ideas added;
- ideas rejected;
- open questions.

## Foundation updates

List foundation updates made or needed.

Include:

- Constitution changes;
- Product Vision changes;
- Domain Model changes;
- Architecture Principles changes;
- Capability Matrix changes;
- Product Language changes;
- ADR changes.

## Completion decision

State whether the Epic is complete.

Options:

- Complete;
- Complete with follow-up;
- Blocked;
- Superseded.
