## Realization policy fixed before production changes

The DJMoment Engine performs the same qualified content as Home, Radio, Club
or Festival DJ. Home is warm/curious, Radio polished/narrative, Club compact
and restrained, Festival playful/energetic without permanent hype. Mood may
soften the delivery within a persona; it never changes persona or fact truth.
Use different sentence construction, rhythm and endings rather than adding
the same opener to provider text. Four structural forms for ordinary credits and producer callbacks vary across
actually published contributions; no repeated catchphrase or fabricated personal memory.

Source identity, names, roles, qualifications, current/earlier recording,
edition-versus-original release, date precision and public attribution remain
immutable. Source normalization retains minimal typed display anchors from
already available authorized fields; no fact is extracted from creative text.
The original qualified object is never rewritten to pass qualification.
Malformed/missing anchors fall back to its exact existing localized copy.
Missing source language remains silence, never English under another locale.

The existing shared-producer qualification is the only permission for a
producer callback. Both source proofs and the Runtime's published-only history
must already qualify. Ordinary credit text cannot invent 'again', 'earlier',
influence, collaboration, exclusivity or unheard musical characteristics.
Local rhetorical appreciation describes the contribution, not a new fact or
listener preference. Source links remain conspicuous in the existing consumer.

Other fact families retain a single authored persona realization without a
cyclic-form claim; their qualified anchors and scoring remain intact.

Style memory contains at most six persona/factual-family/form keys, derived only from actual
Flow publication. Proposal, preview and rejected long form do not commit it.
Runtime end clears it. No personal data, raw provider payload, prompt, durable
style knowledge, cross-Session learning or new Moment/Transition type.

Moment Engine previews realization without side effects. Planner keeps its
existing scoring/selection and capability/source gates; read-fit uses final
realized text. A long form tries the exact qualified
copy as a faithful short fallback; if none fits, existing fact alternative or silence applies. Runtime's
final eligibility/generation/current playback checks still precede publication.
Existing 40–90s readable duration, six-card limit, spacing and late-result,
pause/seek/item/source/reconnect/end controls remain. No extra cards or audio.
