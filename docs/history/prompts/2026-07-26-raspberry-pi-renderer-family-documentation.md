# Prompt History: Document Raspberry Pi Renderer Family

**Generation:** Generation 2

**Engineering program:** Platform Evolution documentation polish

**Decision:** `GO_RASPBERRY_PI_RENDERER_FAMILY_DOCUMENTED`

## Evidence and result

This documentation-only increment reconciles the existing CMB-05 and CMB-06
capability-profile decisions with the Raspberry Pi Platform Foundation,
Renderer Host Classification and Renderer Experience Roadmap. It introduces a
compact family reference for the independently assessed native QML Pi 4-inch
and Pi 10-inch shared appliance Renderer Hosts.

The reference adds no capability, implementation, qualification item, roadmap
change, Execution Horizon change or architecture. The Pi 4-inch compact
playback-companion and Pi 10-inch shared wall-appliance boundaries remain
unchanged.
