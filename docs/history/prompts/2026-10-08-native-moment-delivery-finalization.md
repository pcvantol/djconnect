## Product behavior and qualification

The existing owner snapshot/events now carry separate `native_delivery`
schema1 authority: opaque revision, current Moment, permitted active-Flow IDs,
original source/display deadlines, attribution requirement and executable
allowlist. Semantic immutable Moments, text/Persona, Planner, dose and Flow
remain unchanged. No second endpoint, knowledge provider or command engine.

MusicBrainz core entity/relationship fields and Wikidata structured descriptions
qualify under their published CC0 terms. Qualified published same-Session Flow
recall lasts only within original source lifetime30minutes. Spotify metadata is
current-only, requires its existing attribution/mark and link, and cannot become
historical source authority. Unknown sources, ambiguous identity, derived
unqualified transitions and unsupported semantic actions deny native display.
Only validated existing Session Direction qualifies as internal source-free
content. Generic native executable actions remain empty: semantic suggestions
alone do not prove an existing authorized command. Existing player/Ask DJ/
handoff routes retain their own authorization.

Current visibility has the original card deadline, bounded by90seconds and
source expiry; a producer callback uses the shortest of both original source
clocks. Historical media identity never becomes current playback. Expiry removes
source text, Presentation and Flow-label copies from owner snapshots/events,
pending delivery and recovery. Pause/seek/item/output invalidates old current
visibility without resurrecting an older card. Qualified recall may remain.
Existing progress observation updates policy without a new monitor. Receiver
streams do not receive owner-only authority/Flow identity. Reconnect uses the
existing snapshot-required path and original deadlines, never renewed clocks.

Entry-generation-bound subscriptions withdraw on unload using existing
`broadcast_stopped` and empty authority, including pending handshake delivery;
other entries remain active. Terminal setup denial may have no sequence and
must be handled before ordinary event ordering. Session end empties admissions.
No new individual source-revocation API is claimed. Session HTTP JSON success,
auth and malformed/non-object payload errors use no-store/no-referrer.
