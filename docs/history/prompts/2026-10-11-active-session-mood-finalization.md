## Engineering lessons

A value-only in-flight guard misses ABA changes; compare Session-scoped revisions
before state merge and opportunity consumption. Restore only the rejected
candidate's matching media marker so the ordinary observation path can retry.
Resolve current Profile authority again after awaits under the mutation lock;
disabled/archived state and persisted/runtime pairing must both remain valid.
Validate stored identity before a generic authorizer that can learn a pending
setup identity. Same-value success is not a reason to publish another event.

A response confirms its own Session/revision, not the latest UI state. Clients
must reject cross-Session and lower-revision late acknowledgements and refresh
confirmed current choice on conflict. Renderer origin pins and producer delivery
pins are distinct even when unchanged renderer code is packaged together.
Actual HTTP/Broadcast/browser proof and modeled CAF/native/hardware boundaries
must stay explicit. Ordinary re-pair is idempotent; withdrawal fixtures do not
prove an options-flow token rotation.
