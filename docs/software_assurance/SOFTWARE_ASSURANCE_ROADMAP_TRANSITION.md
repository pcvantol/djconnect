# Software Assurance Roadmap Transition

Status: canonical transition note  
Scope owner: `pcvantol/djconnect`

The Software Assurance architecture sprint is complete.

The next platform step is not Software Assurance implementation.

The platform returns to the active Verification roadmap until the mandatory
Software Assurance implementation prerequisites are complete:

- primary adapter qualification;
- cross-platform qualification;
- stable Verification Runtime release;
- Platform Baseline update.

After those prerequisites, Software Assurance implementation may begin with the
Wave 1 Static Quality rollout.
