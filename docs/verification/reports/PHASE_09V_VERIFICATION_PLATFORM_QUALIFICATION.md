  mandatory PASS.
- The Verification Investigator exists only as documented workflow guidance;

scenario failures.

## Recommendations

1. Start or configure the local Home Assistant development runtime.
2. Provide `DJCONNECT_VERIFICATION_HA_URL`,
   `DJCONNECT_VERIFICATION_HA_TOKEN` and
   `DJCONNECT_VERIFICATION_HA_STORAGE_DIR`.
3. Re-authenticate `gh` or make GitHub connector commit/check status the
   official CI source.
4. Extend the existing Verification Core/reporting subsystem with an executable
   Investigator.
5. Persist qualification evidence under `artifacts/verification/evidence/`.
6. Add live websocket transport support through the existing HA adapter
   transport hook.
7. Emit deterministic data seed and generator version metadata in planning/run
   evidence.
