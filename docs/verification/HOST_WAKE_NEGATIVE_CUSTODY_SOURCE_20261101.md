## Implemented boundaries

The normal Direct rich service owns one bounded child registry. An actual
pre-body paired request captures its original task and wall/monotonic budget;
its request-owned completion hook releases the pair after response handling.
Body waits, SQLite finalizers and private role transport cannot select a newer
request, owner, source or deadline. Parent retirement synchronously closes its
positive dependents; a spent child scope is not evicted or refunded.

The private receiving codecs retain original API request/reply correlations,
proof kind, target and policy hashes. The actual role lookup derives its scope
from the original paired context and already-loaded installation credential.
Caller mutation cannot substitute another received role or change a mapping
while SQLite waits. Issuer preparation consumes and retains the exact SQL
claim and its preallocated UUID; it does not perform an issuer effect.

Schema 21 appends two tables without changing migration 1–20 identities. The
existing FULL-sync transaction guards preserve original ownership, consumed
attempts, revisions and cancellation across commit. SQL metadata cannot restore
a positive RAM owner, credential, native permission or unknown operation.

The prebound installation port can only withdraw its own original issuer
scope. Local child closure precedes scheduling. Its sole 30-second execution
window starts before the worker is queued; a duplicate cannot cancel the
original attempt. Pair/Session retirement does not reacquire authority. Entry
unload, service shutdown, configuration replacement, cancellation and terminal
completion release its retained references. Unknown remains inconclusive.

Local status/withdraw management uses the same original pre-body pair and
actual committed linked-profile snapshot. It checks the immutable reservation's
six ownership fields, scope and native operation before closing a child. Ended
Sessions and retired positive parents remain history-readable. Status failure,
wrong scope or request cleanup cannot close the original child. Returned local
journal metadata is not a remote withdrawal acknowledgement or a public native
success response.
