## Qualification boundaries

`semantic_reads` is a mandatory paid profile in the existing release matrix.
Its50 held-out questions span10 cases in each ofen/nl/de/fr/es: artist,
recording, edition date, other album tracks, queue, Forecast, previous recording,
alternative album offer, selected playback A while provider B is current, and
a current-context question previously captured incorrectly as a public name.
These questions are neither runtime recognition rules nor prompt examples.
They must remain unresolved by the literal recognizers so that this profile
actually qualifies model interpretation. New phrases still need empirical
evaluation; no finite sample proves every future wording correct.

Real isolated HA pairing, the common HTTP/Ask DJ owner, configured HA agent and
real GPT-6 Luna calls are exercised. Only external catalog/playback I/O is fixed
synthetic data. The lab normally stops its own observation poller before changing
the A/B fixture; production guards are unchanged. Separate negative owner tests
exercise clear/end/new-Session races during interpretation and preserve the
original captured scope through delivery. No installed HA config is mounted.

The plan is duplicate-safe, size bounded and closed to extra fields. An invalid
plan, unsupported reference or unavailable agent cannot mint an effect, choose a
replacement recording, buy a format-repair call or return unchecked model facts.
Private/injection/gibberish exclusions precede the new call. Current and selected
context retain existing Profile, account, source, Session/item and expiry fences.
Inherited qualified CC0 subjects cannot silently determine a current-playback
question: a readplan can use the existing first research-generation call while
factual prose still requires its second independent assessment.

A selected Artist contribution may qualify a performer without qualifying a
recording. Recording questions require actual recording metadata; otherwise the
localized answer explicitly says the recording is unknown, keeps the selection
and does not fall back to current playback. Causal negative owner proof uses an
actually published Artist/CC0 Moment, not an invented response dictionary.
