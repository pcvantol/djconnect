# Meta Engineering Index

**Status:** Canonical Navigation

**Audience:** Humans, AI agents, reviewers and maintainers

**Scope:** Entire DJConnect platform

---

# Purpose

This index is the canonical navigation page for the DJConnect Meta Engineering
Foundation.

Meta Engineering explains how engineering work is performed, how humans and AI
agents collaborate and where durable engineering knowledge belongs.

It does not replace Foundation, Verification, Technical Design, Prompt Library
or Completion Report documents.

# Relationship To Other Canonical Areas

## Foundation

Foundation documents define product direction, platform principles, governance,
ownership and accepted platform intent. Meta Engineering defines the engineering
process used to preserve and evolve that foundation.

## Verification

Verification documents define expected behavior, evidence and qualification.
Meta Engineering defines the repository-first, evidence-first discipline used
while building and maintaining verification assets.

## Technical Design

Technical Design documents implementation reality. Meta Engineering defines how
new technical discoveries are classified and moved into the correct canonical
document.

## Prompt Library

Prompts are execution instructions. They reference canonical documentation.
They are not the source of architectural truth.

## Completion Reports

Completion Reports describe what happened in a phase. Meta Engineering explains
why phase results, lessons and follow-up work should become durable repository
knowledge.
